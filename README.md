# Price Tracker

Εφαρμογή για Windows που παρακολουθεί **τιμή** και **διαθεσιμότητα** προϊόντων σε καταστήματα της **Ελλάδας** και της **Ε.Ε.**
Κρατάει ιστορικό τιμών με γραφήματα, ώστε να φαίνεται αν μια προσφορά στη Black Friday ή στη Cyber Monday είναι πραγματική.
Σε κάθε εύρεση τραβάει **screenshot** που δείχνει το κατάστημα, το προϊόν και την τιμή, για να έχεις αποδεικτικό.

Όλα τα δεδομένα μένουν **τοπικά στον υπολογιστή σου**, στον φάκελο `Έγγραφα\PriceTracker`.

## Τι κάνει

- **Κατηγορίες** (π.χ. Κουζίνες, Τροφοδοτικά PSU) με δημιουργία, μετονομασία και διαγραφή.
- **Προσθήκη προϊόντος με link**: επικολλάς το link από ένα κατάστημα. Η εφαρμογή διαβάζει όνομα, τιμή, EAN και κωδικό
  κατασκευαστή και μετά **ψάχνει το ίδιο προϊόν στα άλλα καταστήματα**. Οι αντιστοιχίες που βρίσκει εμφανίζονται για
  επιβεβαίωση (✔ / ✕), γιατί μια αναζήτηση μπορεί να φέρει και παρόμοιο μοντέλο.
- **Ξεχωριστές ομάδες Ελλάδα / Ε.Ε.**, με την καλύτερη διαθέσιμη τιμή για την καθεμία.
  - Ελλάδα: BestPrice, Plaisio, Kotsovolos, Public, e-shop.gr, MediaMarkt
  - Ε.Ε.: Amazon.de/.it/.fr/.es, eBay.de, Mindfactory, Caseking
  - Όποιο άλλο κατάστημα προσθέσεις με link μπαίνει μόνο του στην ομάδα που του αντιστοιχεί (π.χ. `.gr` στην Ελλάδα, `.de` στην Ε.Ε.).
- **Έλεγχοι**: όταν ανοίγει η εφαρμογή και μετά **κάθε 6 ώρες**. Από **20/11 έως 2/12** (περίοδος Black Friday) κάθε **1 ώρα**.
  Και τα δύο διαστήματα αλλάζουν από τις Ρυθμίσεις.
- **Γράφημα εξέλιξης τιμής** ανά κατάστημα, με σημάδια για Black Friday και Cyber Monday.
- **Εκτίμηση προσφοράς**: σύγκριση με τη χαμηλότερη και τη συνήθη τιμή των προηγούμενων 30 και 90 ημερών. Εντοπίζει και
  το κόλπο «ανεβάζω την τιμή πριν τη Black Friday και μετά κάνω έκπτωση».
- **Screenshots** όταν αλλάζει η τιμή ή η διαθεσιμότητα, και σε κάθε έλεγχο της περιόδου Black Friday.
- **Ειδοποιήσεις email** (Gmail) όταν ένα προϊόν γίνει διαθέσιμο, φτάσει την τιμή-στόχο ή πέσει σε νέα χαμηλότερη τιμή.
  Τα screenshots πηγαίνουν συνημμένα. Εμφανίζεται και ειδοποίηση των Windows.
- **«Αγοράστηκε»** με τιμή, ημερομηνία και κατάστημα. Τα αγορασμένα προϊόντα δεν ελέγχονται πια, αλλά το ιστορικό τους μένει.
  Τα προϊόντα επίσης τροποποιούνται και διαγράφονται.
- **Export σε Excel (.xlsx)**: σύνοψη, πλήρες ιστορικό με links στα screenshots και ένα φύλλο με γράφημα για κάθε προϊόν.
- **System tray**: όταν πατάς το Χ, η εφαρμογή ρωτάει αν θα κλείσει ή αν θα μείνει στο tray για να συνεχίσει τους ελέγχους.
  Μπορεί προαιρετικά να ξεκινάει μαζί με τα Windows.

## Εγκατάσταση

1. Κατέβασε το `PriceTracker-windows.zip`, είτε από τα **Releases** του repo είτε από **Actions → Build Windows app →** τελευταίο run **→ Artifacts**.
2. Αποσυμπίεσέ το σε έναν φάκελο, π.χ. `C:\Programs\PriceTracker`.
3. Άνοιξε το `PriceTracker.exe`. Την πρώτη φορά τα Windows μπορεί να δείξουν «Τα Windows προστάτευσαν τον υπολογιστή σας»,
   επειδή το πρόγραμμα δεν έχει ψηφιακή υπογραφή. Πάτα **Περισσότερες πληροφορίες → Εκτέλεση οπωσδήποτε**.

Για τους ελέγχους η εφαρμογή χρησιμοποιεί τον **Microsoft Edge** που υπάρχει ήδη στα Windows, άρα δεν χρειάζεται να εγκαταστήσεις τίποτα άλλο.

Αν προτιμάς να το τρέξεις από τον κώδικα, χρειάζεσαι Python 3.13 ή νεότερη. Μετά κάνεις διπλό κλικ στο `run.bat` ή φτιάχνεις
το `.exe` με το `build.bat`.

## Ρύθμιση email (Gmail)

1. Στο https://myaccount.google.com/security ενεργοποίησε την **Επαλήθευση σε 2 βήματα**.
2. Στο https://myaccount.google.com/apppasswords φτιάξε έναν **κωδικό εφαρμογής** (όνομα: Price Tracker). Θα πάρεις 16 χαρακτήρες.
3. Στην εφαρμογή πήγαινε **Ρυθμίσεις → Ειδοποιήσεις email**: πάροχος Gmail, το Gmail σου, ο κωδικός εφαρμογής και η διεύθυνση
   που θα λαμβάνει τις ειδοποιήσεις (μπορεί να είναι και το Hotmail σου).
4. Πάτα **Αποστολή δοκιμαστικού email**.

Ο κωδικός αποθηκεύεται στη **Διαχείριση διαπιστευτηρίων των Windows**, όχι σε απλό αρχείο.

## Περιορισμοί

- Οι έλεγχοι γίνονται μόνο όσο ο υπολογιστής είναι ανοιχτός και η εφαρμογή τρέχει (έστω και στο tray).
- Η **Amazon** μερικές φορές ζητάει captcha. Τότε ενεργοποίησε το «Εμφάνιση του browser κατά τον έλεγχο» στις Ρυθμίσεις.
- Για την Amazon/eBay η εφαρμογή δείχνει αν το προϊόν είναι διαθέσιμο, **όχι** αν στέλνεται στην Ελλάδα. Αυτό θέλει ακόμα έλεγχο από εσένα.
- Αν ένα κατάστημα αλλάξει τη σελίδα του, μπορεί να σταματήσει να διαβάζεται η τιμή. Θα το δεις ως «σφάλμα ελέγχου» στο προϊόν.
  Το URL αναζήτησης κάθε καταστήματος αλλάζει από τις Ρυθμίσεις.

## Φάκελος δεδομένων

`Έγγραφα\PriceTracker\`
- `pricetracker.db`: η βάση (προϊόντα, κατηγορίες, ιστορικό). Για αντίγραφο ασφαλείας, κράτα αντίγραφο ολόκληρου του φακέλου.
- `screenshots\`: ένας φάκελος ανά προϊόν.
- `exports\`: τα αρχεία Excel.
- `app.log`: αρχείο καταγραφής για διάγνωση προβλημάτων.

## Για προγραμματιστές

```
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements-dev.txt
python -m pricetracker            # παράθυρο εφαρμογής
python -m pricetracker --browser  # στον browser (http://127.0.0.1:48231)
python -m pytest
```

Δομή: `pricetracker/extract.py` (ανάγνωση τιμής: JSON-LD, meta, κανόνες Amazon/eBay), `search.py` (αναζήτηση σε άλλα καταστήματα),
`worker.py` (έλεγχοι, χρονοπρογραμματισμός, ειδοποιήσεις), `analysis.py` (εκτίμηση προσφοράς), `web.py` + `static/` (περιβάλλον),
`app.py` (παράθυρο, tray).
